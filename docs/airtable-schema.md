# Airtable Schema — Door Knock

The district's Airtable base is the admin-facing mirror of Supabase. Field
activity flows **back** into Airtable in 2-minute batches so admins can work in
a familiar surface.

## Target Voters (existing, add fields)

| Field | Type | Notes |
| --- | --- | --- |
| Lat | Number | Populated by `import-district.ts` |
| Lng | Number | Populated by `import-district.ts` |
| GeocodedAt | DateTime | ISO timestamp |
| HouseholdLink | Linked → Households | |
| CurrentStatus | Single select | Synced from Supabase |

## Households (new)

`HHRecId` (primary), `Address`, `City`, `State`, `Zip`, `Lat`, `Lng`, `Status`
(single select), `VoterCount` (rollup), `LastKnockedAt` (synced).

## Walkbooks (new)

`Name`, `District`, `HouseholdCount`, `Centroid` (text "lat,lng"), `Status`,
`AssignedTo` (→ Users), `AutoGenerated` (checkbox).

## Users (new)

`Email`, `FullName`, `Role` (single select), `Active`, `AssignedWalkbooks`.

## Surveys + Survey Questions (new)

Surveys: `Name`, `Description`, `Active`, `Visibility`, `Priority`, `Questions`
(→ Survey Questions).

Survey Questions: `Survey`, `Order`, `QuestionText`, `QuestionType`,
`Required`, `Options` (long-text JSON).

## Tags (new)

`Label`, `Color`, `IsStandard`, `CreatedBy`, `UsageCount`.

## Knock Events (new, read-only mirror)

`KnockedAt`, `Knocker`, `Household`, `Voter`, `Status`, `Notes`.
